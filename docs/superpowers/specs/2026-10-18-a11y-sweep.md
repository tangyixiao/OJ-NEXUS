# Accessibility sweep — Spec

Date: 2026-10-18
Phase: 112 (docs/LONG_RANGE_PLAN.md:296-299)

## Goal

Full a11y audit (talkback order, contrast, font scale 200% at 320dp) with a checklist per
screen, fixing all critical findings.
Refs: `docs/verification/2026-10-01-android-shared-layout.md`.

## Method on this host (no emulator attached)

No device/emulator is attached, so TalkBack ordering and font-scale screenshots cannot be
*observed* directly. Instead the sweep is a **static source audit** over every screen
composable, checking the properties that deterministically produce correct TalkBack output:

1. Touch targets: every `clickable` element has a contentDescription or text label
   (TalkBack reads it) — grep for `clickable` without a sibling `semantics`/text.
2. State announced: non-color-only state (verdict tags already carry text per AGENTS.md).
3. Decorative vs meaningful images/icons.
4. Trailing-label clickables: rows where a *trailing* text is separately clickable — the
   classic TalkBack trap (two targets, first swallows the row).

Findings are classified CRITICAL (blocks a screen for TalkBack users) / MINOR (works but
suboptimal) and CRITICALs are fixed in this phase.
