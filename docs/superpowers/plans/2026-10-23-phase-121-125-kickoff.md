# OJ NEXUS Phase 121–125 Kickoff Implementation Plan

> **For agentic workers:** use `superpowers:executing-plans` or explicitly authorized
> subagent-driven execution phase by phase. This file is a future execution handoff, not
> evidence that any phase has run.

Execution started 2026-10-23. Task 1 is recorded in
[Phase 121 baseline](../../verification/phase-121-baseline.md); other tasks retain independent
build/runtime/release gates and are not completed by this audit.

**Goal:** establish a truthful, reproducible baseline on four native platforms before expansion.

**Architecture:** inspect existing implementations, keep platform data stores independent,
capture reproducible evidence and fix only confirmed baseline defects in the owning phase.

**Tech Stack:** existing Kotlin/Compose, C#/WPF, C++/Qt, Swift/SwiftUI and CI workflows.

**Spec:** [design](../specs/2026-10-23-balanced-100-phase-roadmap-design.md) and
[authoritative roadmap](../../LONG_RANGE_PLAN_121_220.md), sections 1–4.

## Global Constraints

- All 121–220 phases begin PLANNED. No implementation is authorized by this file alone.
- Repository AGENTS.md and the roadmap's security/design rules apply to every task.
- Platform acceptance is implementation + fresh build/tests + runtime evidence + release status.
- No machine-local Gradle paths, credential material or unrelated worktree changes are committed.
- Failure fixes need a reproducible cause and a regression that exercises the user-visible risk.
- Draft PR creation and qualified release publication are authorized; PR merge is a separate action.

## Review Focus

1. Historical completed labels can hide missing device evidence; Task 1 must list those gaps.
2. Windows commands/SQL may exist without WPF reachability; Task 3 must exercise actual controls.
3. Linux files are outside main; Task 4 must review integration rather than copy directories.
4. Apple CI can compile without running either app; Task 5 must record separate runtime results.
5. A successful build does not qualify an APK/installer for production distribution; preserve signing labels.

## Wave 01 exit

Each platform can finish independently. A wave is fully verified only when all required phase
gates pass; if one host is missing, report a partial wave and carry its blocking item forward.
Evaluate platform RC releases from reviewed commits with usable assets and checksums. Do not
publish a four-platform stable release when only Android/Windows have runtime evidence.
