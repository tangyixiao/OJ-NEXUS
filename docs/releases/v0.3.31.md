# OJ NEXUS v0.3.31 — Luogu Rating history fallback / 洛谷 Rating 历史回退

## Highlights / 重点

- Preserve public Luogu Rating history when `/user/{uid}/practice` returns an empty `elo` array. / 当 practice 返回空 `elo` 数组时保留洛谷公开 Rating 历史。
- Prefer non-empty practice history and fall back to the public user-page history. / 优先使用非空 practice 历史，回退到公开用户主页历史。
- Add a regression test matching the real response shape observed for public accounts. / 增加覆盖真实公开账号响应结构的回归测试。

## Safety boundary / 安全边界

This release remains local-first and public-data-only. It does not add Luogu main-site passwords,
cookies, sessions, CSRF login, cloud accounts, cross-device sync, local compilation, custom-input
execution, automatic submission POST retry, or private submission-history import. / 本版本继续本地优先、
仅公开数据，不新增洛谷主站密码、Cookie、Session、CSRF 登录、云端账号、跨设备同步、本地编译器、自定义输入
运行器、自动提交 POST 重试或私有提交历史导入。
