# OJ NEXUS v0.3.47 — Legacy submission title backfill / 回填旧提交题名

## Highlights / 重点

- Upgrading from the pre-title Room schema backfills missing local submission titles from
  cached remote problem details, then the local problem library. / 从旧版 Room 结构升级时，优先使用缓存的远程题面详情、
  再使用本地题库，为缺失题名的本地提交记录回填标题。
- Existing titles are preserved, blank cache titles are ignored, and unmatched records remain
  safely PID-only. / 已有题名保持不变，空缓存题名会被忽略，没有匹配缓存的记录安全地保持仅 PID 显示。
- The package identity is `versionName=0.3.47`, `versionCode=47`. / 安装包身份为
  `versionName=0.3.47`、`versionCode=47`。
- The signed APK is accompanied by `SHA256SUMS-v0.3.47.txt`. / 签名 APK 同时附带
  `SHA256SUMS-v0.3.47.txt`。

## Safety boundary / 安全边界

This is a local, non-destructive Room migration. It does not add network fields, main-site
passwords, Cookie, Session, CSRF state, cloud service, cross-device sync, local compiler,
custom-input runner, background submission, or automatic POST retry. / 本版本是本地、非破坏性的 Room
迁移，不新增网络字段、主站密码、Cookie、Session、CSRF 状态、云服务、跨设备同步、本地编译器、自定义输入运行器、后台提交或自动
POST 重试。
