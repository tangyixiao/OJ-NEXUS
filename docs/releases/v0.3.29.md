# OJ NEXUS v0.3.29 — Luogu OpenApp focus / 洛谷 OpenApp 定位

## Highlights / 主要变化

- **Focused setup route / 定位配置路由** — The workspace `OPEN SETTINGS` action now enters
  `settings/openapp` and brings the `LUOGU OPEN PLATFORM` section into view. 工作区“打开设置”现在进入
  `settings/openapp`，并自动定位到“洛谷 Open Platform”区域。
- **Ready-to-configure controls / 直接可配置控件** — OpenApp documentation, user, secret, and
  `SAVE CREDENTIAL` are visible after navigation. 进入后可以直接看到 OpenApp 文档、用户名、密钥和“保存凭据”。
- **Ordinary Settings preserved / 普通设置保持不变** — The existing `settings` route remains
  top-aligned; only the workspace-originated route requests focus. 原有 `settings` 路由仍从顶部开始，只有
  从工作区进入时才请求定位。
- **Safety boundary / 安全边界** — This is a local navigation improvement only. No main-site
  password, Cookie, Session, CSRF login, cloud account, cross-device sync, local compiler,
  custom-input runner, or automatic submission retry was added. 本版本仅改善本地导航，不新增主站密码、
  Cookie、Session、CSRF 登录、云端账号、跨设备同步、本地编译器、自定义输入运行器或自动提交重试。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and commit explanations use
  English + Chinese. Earlier phase notes and Releases remain preserved. README、路线图、本 Release 和 commit
  说明使用中英文结合；此前阶段说明和 Releases 继续保留。
