# OJ NEXUS v0.3.46 — Submission workspace title restoration / 提交工作区题名恢复

## Highlights / 重点

- Submission Center now reopens a Luogu workspace with its locally stored problem title when
  available. / 提交中心现在会在题名可用时，携带本地保存的题目标题重新打开洛谷工作区。
- PID remains the only problem/submission identity. / PID 仍是唯一题目和提交身份。
- Null or blank legacy titles continue to use the PID-only route. / 旧记录的空题名继续使用仅 PID 路由。
- No network DTO, database schema, or credential flow was added. / 未新增网络 DTO、数据库结构或凭据流程。
- Package identity is `versionName=0.3.46`, `versionCode=46`. / 安装包身份为
  `versionName=0.3.46`、`versionCode=46`。
- `SHA256SUMS-v0.3.46.txt` accompanies the signed APK. / 签名 APK 附带
  `SHA256SUMS-v0.3.46.txt`。

## Safety boundary / 安全边界

This is a local navigation/display-context change. It does not add main-site passwords, Cookie,
Session, CSRF state, cloud service, cross-device sync, local compiler, custom-input runner,
background submission, or automatic POST retry. / 本版本仅改变本地导航和展示上下文，不新增主站密码、Cookie、
Session、CSRF 状态、云服务、跨设备同步、本地编译器、自定义输入运行器、后台提交或自动 POST 重试。

## Verification / 验证

```text
git diff --check

```

The signed APK is installed over the existing emulator app without clearing data. The emulator
remains online; no shutdown or data reset is performed. / 签名 APK 在不清除数据的情况下覆盖安装到现有模拟器。
模拟器保持在线，不执行关机或数据重置。

Earlier release notes, commits, tags, and published Releases remain preserved. /
更早的发布说明、commit、标签和已发布 Release 均保留。
