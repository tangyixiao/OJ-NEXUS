# OJ NEXUS v0.3.22 — Foreground Luogu catalog action / 前台洛谷题库操作

## Highlights / 主要变化

- **Explicit catalog sync / 显式同步题库** — The Luogu remote Problems scope now has a
  foreground `SYNC CATALOG` action. It can import the public catalog without a connected account.
  洛谷远端题库现在提供前台“同步题库”操作，无需连接账号即可导入公开题库。
- **Visible state / 可见状态** — The action shows syncing, imported-item count, and failure text;
  repeated taps while busy are ignored. 操作会显示同步中、导入数量和失败信息，同步期间重复点击会被忽略。
- **Live dump compatibility / 兼容真实导出数据** — Rows with a valid `pid` but an empty title
  are accepted and use the problem ID as the honest display fallback. 对真实公开导出中“题号有效、
  标题为空”的记录予以兼容，并使用题号作为明确的显示兜底。
- **Local-first safety / 本地优先安全边界** — Room remains the read source and bounded writes
  preserve already-imported rows after a failed run. Room 仍是读取源，同步失败时保留已写入的题目。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and the commit explanation
  remain English + Chinese; previous phase notes and Releases were not removed. README、路线图、本
  Release 和 commit 说明继续中英文结合，之前的阶段说明和 Releases 没有删除。

## Scope / 范围

This is a public-data-only, foreground, local-first improvement. It does not add Luogu main-site
password, cookie, session, CSRF login, cloud account, cross-device sync, background work from the
button, or automatic POST retry. / 本阶段只改进公开数据、前台、本地优先流程；不新增洛谷主站密码、
Cookie、Session、CSRF 登录、云端账号、跨设备同步，不由按钮创建后台任务，也不增加 POST 自动重试。
