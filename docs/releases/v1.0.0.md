# v1.0.0 Release Candidate — Release Notes

Date: 2026-10-18
Version: 1.0.0 (versionCode 102)

## What v1.0.0 means

OJ NEXUS 1.0.0 is the first release-candidate line. It is a local-first competitive-programming
command center for Codeforces, AtCoder, and Luogu: everything on this list ships in the APK,
nothing requires an account beyond the judges' public handles, and no credential ever leaves
the device.

## Feature inventory at 1.0.0 (all verified by phase gates)

- **Problem library** — 10,000-row windowed list (60-row windows), judge/status/difficulty/tag
  filters, favorites, per-row favorite toggles.
- **Problem detail** — remote metadata, attempts with verdicts, notes, knowledge links, tags,
  favorite, per-attempt Codeforces deep links (exact contest/submission URL), unified
  submission detail sheet.
- **Review system** — PASS/HARD/FAIL/SKIP ladder over intervals [1, 3, 7, 21, 45, 90] days,
  due queue, review log, mastery decay.
- **Training** — focus sprint with EASIER/FIT/STRETCH difficulty bands and reason codes;
  session screen with notes, debrief export (Markdown share).
- **Analytics** — solve heatmap with formatted-date accessibility labels, streaks, rating
  history, per-judge totals.
- **Contests** — center + focus screens; AtCoder rating history from the official public
  endpoint; Codeforces problemset delta sync (fingerprint skip).
- **Luogu** — open-platform submit-and-poll, quota probe, public training catalog (lentille
  codec, typed failures).
- **Data ownership** — snapshot export/import (zip + manifest, per-table conflict preview),
  scheduled local backups to SAF trees (daily/weekly, keep-last-N), per-judge data wipe behind
  typed confirmation, database size/housekeeping panel with VACUUM, opt-in local crash log.
- **Command palette** — direct queries for review run, sprint plan, unsolved ranges.
- **Multi-platform** — Windows CLI (status/sync/data/history/problems/review/config) + WPF
  dashboard sharing the same sync ledger, Inno Setup installer, opt-in Authenticode signing,
  schema v7 review parity.

  (`tools/check-reproducible-build.ps1`).

- Room schema v14 with migration-tested index additions; cold-start tracing against the 1.5 s

## Known deferrals (honest, by design)

- Device-loop measurements (cold start, battery, 20-minute LeakCanary walk, TalkBack pixel
  pass, per-query wall-clock) stay **PENDING** until real hardware runs — all infrastructure is
  in place and every number is documented as pending, never invented.
- Apple clients (Phases 102/103) require a macOS host; the Swift package layout exists in the
  plan but nothing is shipped or faked.
- Multi-handle per judge is design-gated behind a verified spec (Phase 97) with no migration
  committed yet.
- Arc G (optional connected layer) remains RFC-only territory; cutting it is a valid outcome.

## Data boundaries (unchanged, permanent)

No passwords, cookies, or session tokens — ever. The Luogu open-platform credential lives in
no-backup storage and never enters backups, exports, or logs. Snapshot archives contain only
database rows + manifest; a no-secret scan runs in tests. Crash reports are opt-in and local
only. The app never uploads analytics.
