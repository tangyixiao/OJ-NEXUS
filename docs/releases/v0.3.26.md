# OJ NEXUS v0.3.26 — Background sync startup reconciliation / 后台同步启动校准

## Highlights / 主要变化

- **Restart-safe periodic sync / 重启后周期同步恢复** — Existing active accounts now restore
  their six-hour `JudgeSyncWorker` schedule when the app starts. 应用启动时现在会为已有活跃账号恢复
  六小时 `JudgeSyncWorker` 周期任务。
- **Capability-aware / 按能力筛选** — Only registered judges advertising `BACKGROUND_SYNC` are
  considered; missing and disabled accounts are skipped. 只处理已注册且声明 `BACKGROUND_SYNC` 能力的
 评测平台；缺失或已禁用账号会跳过。
- **Failure isolation / 异常隔离** — A scheduler error for one judge does not block other judges from
  being restored. 单个平台调度异常不会阻塞其他平台恢复。
- **Visible capability / 能力可见** — Settings shows `BACKGROUND SYNC ENABLED — EVERY 6 HOURS`
  for connected capable judges. 设置页会为已连接且具备能力的平台显示“后台同步已启用 — 每 6 小时”。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and commit explanations use
  English + Chinese. Previous phase notes and Releases remain preserved. README、路线图、本 Release
  和 commit 说明使用中英文结合；之前的阶段说明和 Releases 继续保留。

## Safety boundary / 安全边界

This release restores scheduling only; startup reconciliation does not trigger an immediate sync and
does not create submission work. Existing judge adapters and local-first storage remain the data path.
No main-site password, Cookie, Session, CSRF login, cloud account, cross-device sync, local compiler,
or custom-input runner is added. / 本版本只恢复任务调度；启动校准不会立即执行同步，也不会创建提交任务。
数据路径仍是现有评测平台适配器和本地优先存储。不新增主站密码、Cookie、Session、CSRF 登录、云端账号、
跨设备同步、本地编译器或自定义输入运行器。
