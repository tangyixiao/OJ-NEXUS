# OJ NEXUS v0.3.71 — Safe Restore

## Included

- Validates imported SQLite files against the current schema, integrity checks, and required Room tables.
- Stages imports privately and applies them before Room opens with journaled atomic replacement.
- Retains database WAL/SHM companions for rollback after a failed or interrupted swap.
- Carries local data generation in sync and Luogu result work; stale work exits before remote access.
- Shows a dismissible localized restore outcome in Settings.

## Safety boundary

Restore metadata contains only typed stage/failure state and an opaque generation marker. It does
not contain credentials, cookies, OpenApp secrets, source code, custom input, or problem content.
