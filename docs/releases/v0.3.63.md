# v0.3.63 — Review Run

## Scope

- Added a continuous `REVIEW RUN` route from Training's due-review pulse.
- The run captures due and overdue reviews once in deterministic due-time/problem-ID order.
- Added `DONE / LEFT / TOTAL` progress metrics and a determinate progress rail.
- PASS, HARD, FAIL, and SKIP use the existing review scheduler and transaction.
- Each result is shown before the user explicitly advances with `NEXT ITEM`; the final state is
  `RUN COMPLETE` with `CLOSE RUN`.
- Individual queue/debrief review navigation remains unchanged.
- No network, schema migration, background work, credentials, or new review result was added.
