# v0.3.68 — Session Momentum

## Highlights

- Active training sessions expose a local `NOW / NEXT / LEFT` momentum rail.
- Recording a local verdict advances ephemeral selection to the next pending queue row when one
  exists.
- `OPEN NEXT` routes through the existing local problem-detail action.
- An all-resolved queue reports completion without inventing a next item.
- Repeated local actions are ignored while the Room-backed transaction is in flight, and failed
  actions preserve the current selection.

## Scope

This phase remains local-first. It adds no network request, automatic OJ submission, credential or
session storage, database migration, persisted selection, or background work.
