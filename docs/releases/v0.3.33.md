# OJ NEXUS v0.3.33 — Sync receipt / 同步回执

## Highlights / 重点

- Settings now shows a capability-backed sync receipt for every connected judge. / 设置页现在为每个已连接评测平台显示基于真实能力的同步回执。
- Supported Profile, Rating, submissions, contests, and problemset modules report their last refresh age. / 支持的资料、Rating、提交、竞赛和题库模块显示最后更新时间。
- Unsupported Luogu private submission history remains outside the public sync receipt. / 洛谷不支持的私有提交历史仍不进入公开同步回执。

## Safety boundary / 安全边界

This release reuses existing local Room timestamps and adds no network endpoint or schema
migration. Luogu remains local-first and public-data-only; there are no main-site passwords,
cookies, sessions, CSRF login, cloud accounts, cross-device sync, local compilation, custom-input
execution, automatic submission POST retry, or private submission-history import. / 本版本复用现有本地
Room 时间戳，不新增网络接口或数据库迁移。洛谷继续本地优先、仅公开数据；不新增主站密码、Cookie、Session、
CSRF 登录、云端账号、跨设备同步、本地编译器、自定义输入运行、自动提交 POST 重试或私有提交历史导入。
