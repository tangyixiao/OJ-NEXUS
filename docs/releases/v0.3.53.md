# OJ NEXUS v0.3.53 — Contest Command Center / 竞赛指挥中心

## Highlights

- Added a local `CONTEST PULSE` with live, upcoming, recent, and next-contest readouts.
- Added local `ALL`, `LIVE`, `UPCOMING`, and `RECENT` phase filters without changing synced data.
- Added `OPEN NEXT` for the earliest upcoming contest; it uses the existing contest-focus route
  and remains disabled with `NO UPCOMING` when the local list has no upcoming row.
- Kept judge filtering, per-second countdown refresh, contest rows, empty states, and focus
  navigation intact.
- Added reduced-motion-safe 200ms count and layout transitions.

Package identity: `versionName=0.3.53`, `versionCode=53`.
