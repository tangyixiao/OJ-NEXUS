# OJ NEXUS v0.3.30 — Public sync queue visibility / 公开同步队列可见性

## Highlights / 重点

- Persist `QUEUED` before manual public judge sync is handed to WorkManager. / 公开评测平台手动同步交给 WorkManager 前持久化 `QUEUED` 状态。
- Show queued, syncing, partial, failed, and successful lifecycle states in Settings. / 设置页显示排队、同步中、部分完成、失败和成功生命周期。
- Map known sync failures to stable localized copy without rendering raw server messages. / 已知同步错误映射为稳定本地化文案，不直接显示服务器原文。
- Keep Luogu public profile, rating, contest, and problem synchronization content-only. / 洛谷资料、Rating、竞赛和题库同步继续只使用公开内容。

## Safety boundary / 安全边界

This release does not add Luogu main-site passwords, cookies, sessions, CSRF login, cloud
accounts, cross-device sync, local compilation, custom-input execution, automatic submission
POST retry, or private submission-history import. / 本版本不新增洛谷主站密码、Cookie、Session、CSRF 登录、
云端账号、跨设备同步、本地编译器、自定义输入运行器、自动提交 POST 重试或私有提交历史导入。
