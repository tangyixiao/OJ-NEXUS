# OJ NEXUS v0.3.44 — Foreground submission result convergence / 前台提交结果闭环

## Highlights / 重点

- An explicit Luogu Open Platform submission now starts the existing bounded foreground result
  check immediately. / 用户明确发起洛谷 Open Platform 提交后，现在会立即开始已有的有界前台结果查询。
- Terminal evaluations render without a second tap. / 终态评测无需再次点击即可展示。
- Pending or partial evaluations remain visible and recoverable through `CHECK RESULT`. /
  待处理或部分评测会继续显示，并可通过 `CHECK RESULT` 恢复查询。
- Package identity is `versionName=0.3.44`, `versionCode=44`. / 安装包身份为
  `versionName=0.3.44`、`versionCode=44`。
- `SHA256SUMS-v0.3.44.txt` accompanies the signed APK. / 签名 APK 附带
  `SHA256SUMS-v0.3.44.txt`。

## Safety boundary / 安全边界

The user must still trigger submission in the foreground. This phase never retries a POST,
creates background submission work, requests main-site passwords, Cookie, Session, or CSRF state,
adds cloud or cross-device sync, or adds a local compiler/custom-input runner. / 提交仍必须由用户在前台明确触发。
本阶段不会重试 POST、创建后台提交任务、请求主站密码、Cookie、Session 或 CSRF 状态，也不新增云端/跨设备同步或本地编译器/自定义输入运行器。

## Verification / 验证

```text
git diff --check
.\tools\gradlew-local.bat clean test assembleDebug lintDebug assembleRelease --no-daemon --rerun-tasks --console=plain
```

The signed APK is installed over the existing emulator app without clearing data. The emulator
remains online; no shutdown or data reset is performed. / 签名 APK 在不清除数据的情况下覆盖安装到现有模拟器。
模拟器保持在线，不执行关机或数据重置。

Earlier release notes, commits, tags, and published Releases remain preserved. / 更早的发布说明、commit、标签和已发布 Release 均保留。
