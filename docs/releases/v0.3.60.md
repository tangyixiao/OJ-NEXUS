# v0.3.60 — Session Debrief

## Highlights

- Added a terminal-session `SESSION DEBRIEF` with solved, attention, and pending lanes.
- Added latest in-session verdict and existing-review indicators to each debrief row.
- Added local filters and direct `OPEN REVIEW` / `OPEN` actions.

## Scope

This release is local-only and read-only at the debrief layer. It adds no schema migration,
network request, background work, compiler, credential flow, or new session state.

## Verification

Verification evidence is recorded after the final build and emulator run.
