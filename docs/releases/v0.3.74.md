# OJ NEXUS v0.3.74 — Sync Operations Ledger

## Included

- Persists a bounded per-judge history of sync operations and module outcomes.
- Shows recent sync history, module statuses, and explicit retry actions in the connector center.
- Falls back to a full sync when an adapter does not advertise safe failed-stage retry.
- Records stale data-generation work without invoking an adapter against newer local data.
- Strengthens CI with debug lint, release assembly, and a separate connected-test emulator job.

## Safety boundary

The change remains local-first. It stores operation metadata and typed failure categories only; raw
error messages, credentials, cookies, passwords, and OJ sessions are not persisted. Retry remains
user-triggered and duplicate-safe.
