# OJ NEXUS v0.3.52 — Problem Library 2.0 / 题库 2.0

## What changed

- Added a local `LIBRARY PULSE` with total, visible, solved, and review counts.
- Added `CLEAR FILTERS` for active filter or non-default sort state; it restores the updated-order
  default without changing stored problems.
- Kept search, status, judge, favorite, tag, sort, add, delete, remote catalog, and detail
  navigation behavior intact.
- Added a restrained status rail to local problem rows and explicit favorite/delete accessibility
  actions.
- Animated count and layout changes over 200ms while snapping immediately when reduce motion is on.
