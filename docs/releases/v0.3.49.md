  contest countdown, and enabled judge connections. / Dashboard 开场新增本地读数，展示待复习、本周解决题数、下一场未来竞赛倒计时和已启用的 OJ 连接。

network fields, database migration, main-site passwords, Cookie, Session, CSRF state, cloud
service, cross-device sync, local compiler, custom-input runner, background submission, or
automatic POST retry. / 本版本是在已有 Room/Flow 数据上的本地展示和导航改进，不新增网络字段、数据库迁移、主站密码、Cookie、
Session、CSRF 状态、云服务、跨设备同步、本地编译器、自定义输入运行器、后台提交或自动提交 POST 重试。
