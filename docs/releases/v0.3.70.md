# v0.3.70 — Dashboard Command Surface

## Highlights

- Dashboard now opens with a local `NOW / NEXT / SIGNAL` command surface below the command deck.
- `NOW` selects the first incomplete task for today and routes to Training.
- `NEXT` selects the due review before an upcoming contest, using existing navigation routes.
- `SIGNAL` reports sync attention, linked OJs, or local-ready state and routes to Settings when
  action is useful.
- Empty and non-actionable states remain visibly labeled and accessible.

## Scope

The surface is a projection over existing Room-backed dashboard state and existing navigation
callbacks. It adds no network calls, fake metrics, credentials, database migrations, automatic
submissions, or looping animation.
