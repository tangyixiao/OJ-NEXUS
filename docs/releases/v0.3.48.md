# OJ NEXUS v0.3.48 — Submission title propagation / 提交题名传递

## Highlights / 重点

- A terminal Luogu OpenApp submission now uses its saved local title when creating a missing
  problem-library row. / 洛谷 OpenApp 提交完成后若需新建本地题库记录，现在会使用已保存的本地题名。
- Existing problem rows are preserved, and missing titles still fall back to the PID. /
  已有题目记录保持不变，缺失题名时仍回退到 PID。
- The package identity is `versionName=0.3.48`, `versionCode=48`. / 安装包身份为
  `versionName=0.3.48`、`versionCode=48`。
- The signed APK is accompanied by `SHA256SUMS-v0.3.48.txt`. / 签名 APK 同时附带
  `SHA256SUMS-v0.3.48.txt`。

## Safety boundary / 安全边界

This is a local result-materialization change. It does not add network fields, main-site
passwords, Cookie, Session, CSRF state, cloud service, cross-device sync, local compiler,
custom-input runner, background submission, or automatic POST retry. / 本版本仅改变本地评测结果落库，不新增网络字段、主站密码、
Cookie、Session、CSRF 状态、云服务、跨设备同步、本地编译器、自定义输入运行器、后台提交或自动 POST 重试。

## Verification / 验证

```text
git diff --check
.\tools\gradlew-local.bat clean test assembleDebug lintDebug assembleRelease --no-daemon --rerun-tasks --console=plain
```

The signed APK is installed over the existing emulator app without clearing data. The emulator
remains online; no shutdown or data reset is performed. / 签名 APK 在不清除数据的情况下覆盖安装到现有模拟器。
模拟器保持在线，不执行关机或数据重置。

Earlier release notes, commits, tags, and published Releases remain preserved. /
更早的发布说明、commit、标签和已发布 Release 均保留。
