# OJ NEXUS v0.3.37 — Luogu first-use public sync loop / 洛谷首次使用公开同步闭环

## Highlights / 重点

- Dashboard shows `CONNECT LUOGU` only when no enabled Luogu account is connected. / 当没有启用的洛谷账号时，Dashboard 才显示“连接洛谷”。
- The action opens `settings/luogu` and focuses the existing Luogu public-account panel. / 操作打开 `settings/luogu` 并聚焦已有的洛谷公开账号面板。
- Existing binding, queued sync, profile, Rating, contest, problem, error, and receipt flows are reused. / 复用已有绑定、排队同步、资料、Rating、竞赛、题库、错误和同步回执流程。
- Package identity is `versionName=0.3.37`, `versionCode=37`. / 安装包身份为 `versionName=0.3.37`、`versionCode=37`。
- `SHA256SUMS-v0.3.37.txt` accompanies the APK. / APK 附带 `SHA256SUMS-v0.3.37.txt`。

## Safety boundary / 安全边界

This phase performs local navigation only. It adds no Luogu API, main-site password, Cookie,
Session, CSRF state, cloud account, cross-device sync, local compiler, custom-input runner, or
automatic submission retry. / 本阶段的新增行为仅是本地导航，不新增洛谷 API、主站密码、Cookie、Session、
CSRF 状态、云端账号、跨设备同步、本地编译器、自定义输入运行器或自动提交重试。
