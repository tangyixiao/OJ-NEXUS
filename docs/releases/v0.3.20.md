# OJ NEXUS v0.3.20 — Official Luogu problemset import / 官方题库导入

## Highlights / 主要变化

- **Official catalog source / 官方题库源** — Full Luogu problem synchronization now prefers the
  official `https://cdn.luogu.com.cn/problemset-open/latest.ndjson.gz` gzip NDJSON export.
  洛谷完整题库同步现在优先使用官方 gzip NDJSON 导出。
- **Streaming + bounded writes / 流式读取与有界写入** — The app decompresses and parses one
  problem per line, then upserts Room rows in bounded batches instead of retaining the complete
  dump in memory. 应用逐行解压解析，并以有界批次写入 Room，不把完整导出文件放入内存。
- **Safe fallback / 安全回退** — Adapters without dump support continue to use the existing paged
  catalog endpoint. 不支持官方导出的适配器继续使用既有分页题库接口。
- **Bilingual project record / 双语项目记录** — README, roadmap, design/plan notes, and this
  release note use English + Chinese while historical entries remain unchanged. README、路线图、
  设计/计划记录和本说明采用中英文结合，历史条目保持不变。

## Verification / 验证

- Focused parser, transport, and repository tests passed.
- Full `test`, `assembleDebug`, and `lintDebug` verification is required for this release.
- No main-site password, cookie, session, CSRF login, cloud account, cross-device sync, background
  submission, or automatic POST retry is introduced. 本版本不新增主站密码、Cookie、Session、CSRF
  登录、云端账号、跨设备同步、后台提交或 POST 自动重试。
