# OJ NEXUS v0.3.43 — Workspace problem context / 工作区题目上下文

## Highlights / 重点

- Native Luogu detail → workspace navigation now preserves the live problem title. / 原生洛谷题目详情进入工作区时现在会保留实时题名。
- PID remains the only required submission identity; title is encoded display context. / PID 仍是唯一必需的提交身份，题名只是经过编码的显示上下文。
- PID-only callers remain compatible and blank titles are omitted. / 仅提供 PID 的旧入口继续兼容，空题名会被省略。
- Package identity is `versionName=0.3.43`, `versionCode=43`. / 安装包身份为 `versionName=0.3.43`、`versionCode=43`。
- `SHA256SUMS-v0.3.43.txt` accompanies the signed APK. / 签名 APK 附带 `SHA256SUMS-v0.3.43.txt`。

## Safety boundary / 安全边界

This release changes only local navigation and display context. It does not add main-site
passwords, Cookie, Session, CSRF state, cloud account, cross-device sync, local compiler,
custom-input runner, background submission, or automatic POST retry. / 本版本仅修改本地导航和显示上下文，
不新增主站密码、Cookie、Session、CSRF 状态、云端账号、跨设备同步、本地编译器、自定义输入运行器、后台提交或自动 POST 重试。
