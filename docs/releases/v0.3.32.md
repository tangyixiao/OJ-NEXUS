# OJ NEXUS v0.3.32 — Synced judge data visibility / 同步评测数据可见性

## Highlights / 重点

- Analytics now displays Rating-only data even without local attempts. / Analytics 现在会显示只有 Rating、没有本地做题记录的数据。
- Profile’s Rated contest count includes every connected judge, including Luogu. / Profile 的 Rated 竞赛数包含所有已连接评测平台，包括洛谷。
- Replace obsolete Phase 2 guidance with neutral localized copy. / 用中性本地化文案替换过期的 Phase 2 指引。

## Safety boundary / 安全边界

This release changes only local presentation. Luogu remains local-first and public-data-only;
there are no main-site passwords, cookies, sessions, CSRF login, cloud accounts, cross-device
sync, local compilation, custom-input execution, automatic submission POST retry, or private
submission-history import. / 本版本仅改变本地展示。洛谷继续本地优先、仅公开数据；不新增主站密码、Cookie、
Session、CSRF 登录、云端账号、跨设备同步、本地编译器、自定义输入运行器、自动提交 POST 重试或私有提交历史导入。
