# OJ NEXUS v0.3.21 — Offline-first Luogu details / 本地优先的洛谷题目详情

## Highlights / 主要变化

- **Room v9 detail cache / Room v9 详情缓存** — Native Luogu problem details are stored in a
  judge-scoped local cache after a successful public fetch. 原生洛谷题目详情在公开请求成功后保存到按
  评测平台隔离的本地缓存。
- **Cache-first opening / 缓存优先打开** — Previously viewed details open without a network request,
  so the native statement remains available offline. 已看过的题目详情打开时不再强制请求网络，断网仍可
  阅读原生题面。
- **Explicit refresh / 显式刷新** — The detail screen has a foreground REFRESH action; network and
  timeout failures with an existing snapshot show the cached detail and a retryable warning. 详情页提供
  前台“刷新”操作；已有快照遇到网络或超时失败时显示缓存并提示可重试。
- **Honest failures / 明确错误** — HTTP, authentication, and parse errors are not silently replaced
  by stale data. HTTP、鉴权和解析错误不会被旧数据静默掩盖。
- **Bilingual record / 双语记录** — README, roadmap, design/plan notes, and this Release remain
  English + Chinese; historical entries and Releases are preserved. README、路线图、设计/计划、Release
  说明继续中英文结合，历史条目和旧 Release 保持不变。

## Verification / 验证

- Mapper, repository, ViewModel, and migration tests passed.
- Full `test`, `assembleDebug`, and `lintDebug` verification is required before publishing.
- The feature remains public-data-only, local-first, and OpenApp-only. No main-site password, cookie,
  session, CSRF login, cloud account, cross-device sync, background submission, or automatic POST retry
  is added. / 本功能仍只使用公开数据、本地优先且仅 OpenApp；不新增主站密码、Cookie、Session、CSRF
  登录、云端账号、跨设备同步、后台提交或 POST 自动重试。
