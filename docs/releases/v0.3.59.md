# v0.3.59 — Live Session Board

## Highlights

- Added a reactive `SESSION PULSE` for total, solved, attempted, and pending session problems.
- Added a local `PROBLEM QUEUE` with judge/external IDs, status labels, attempt counts, and direct
  navigation to problem details.
- Hardened the `NEW SESSION` dialog by keeping its problem picker as the only vertical scroll
  container, preventing Compose's infinite-height measurement crash.
- Progress respects the persisted session start/finish window and requires no database migration
  or network behavior.

## Scope

This release is local-only at the progress layer. It adds no background submission, compiler,
credential storage, new session state, or automatic lifecycle transition.
