# OJ NEXUS v0.3.28 — Luogu workspace setup / 洛谷工作区配置入口

## Highlights / 主要变化

- **Direct setup path / 直达配置路径** — An unconfigured Luogu workspace now shows an `OPEN
  SETTINGS / 打开设置` action below the existing credential warning. 未配置凭据的洛谷工作区现在会在
  原有警告下显示“打开设置”操作。
- **Safe navigation boundary / 安全导航边界** — `NexusApp` owns the route and the workspace only
  receives an `onOpenSettings` callback. 导航仍由 `NexusApp` 管理，工作区只接收 `onOpenSettings` 回调。
- **Execution remains gated / 执行仍受保护** — The execute action remains disabled without a
  credential; no password, cookie, session, CSRF, cloud, or automatic submission behavior was added.
  未配置凭据时执行操作仍禁用；没有新增密码、Cookie、Session、CSRF、云端或自动提交行为。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and commit explanations use
  English + Chinese. Previous phase notes and Releases remain preserved. README、路线图、本 Release
  和 commit 说明使用中英文结合；之前的阶段说明和 Releases 继续保留。
