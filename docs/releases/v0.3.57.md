# v0.3.57 — Submission Ops Deck

## Highlights

- Added manual `CHECK PENDING` and `QUEUE FAILED` operations to the local Submission Center.
- Collapsed recent-request rows into a compact inspector layout while retaining valid actions.
- Added localized `DETAILS` / `HIDE DETAILS` expansion for request, compile, judge, output, and resource metadata.
- Added reduced-motion-safe expansion and explicit accessibility state descriptions.

## Scope

This release is local-only. Bulk actions reuse existing foreground result checks and the manual
recovery scheduler. It adds no new jobs, network fields, database migration, credential storage,
cloud service, cross-device sync, local compiler, custom-input runner, background submission, or
automatic POST retry.
