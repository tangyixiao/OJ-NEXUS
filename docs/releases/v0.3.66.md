# v0.3.66 — Problem Library to Training Handoff

## Highlights

- The local Problems library exposes `BUILD FROM VIEW` for the visible result set.
- The existing Training form opens with those problem IDs selected.
- The form defaults to `PRACTICE` and the editable `LIBRARY VIEW` tag.
- No session is written until the existing `START` action is confirmed.

## Scope

This is a local-only, one-shot in-memory handoff. It reuses the existing Training form,
ViewModel, repository, and session transaction. There is no network request, schema migration,
remote training flow, new persisted state, credential storage, or background work.
