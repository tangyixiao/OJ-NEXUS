# v0.3.67 — Session Command Deck

## Highlights

- Active training sessions expose a selectable `PROBLEM QUEUE`.
- Selecting a row reveals `LOG RESULT` actions for the existing unified verdict set.
- Quick verdicts reuse the local `ProblemRepository.addAttempt` transaction and refresh the
  queue, attempt count, solved state, and progress pulse through Room.
- `OPEN` remains an independent local problem-detail action; quick verdicts never submit to an OJ.
- Selection is ephemeral, localized, accessible, and safe under reduced-motion settings.

## Scope

This phase is local-only. It adds no network request, automatic OJ submission, credential or
session storage, database migration, new session state, or persisted selection. Existing session
lifecycle controls and finished-session behavior remain unchanged.
