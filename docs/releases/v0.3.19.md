# v0.3.19 — OpenApp Credential Verification / OpenApp 凭据连接测试

## What changed / 本次更新

- Saving a Luogu OpenApp token now performs an immediate read-only `quotaAvailable` verification. / 保存洛谷 OpenApp Token 后，现在会立即进行只读 `quotaAvailable` 验证。
- Successful verification shows available points immediately. / 验证成功后立即显示可用计费点。
- Unauthorized or forbidden credentials are cleared; network/API failures keep the Keystore value for retry. / 鉴权失败会清除无效凭据；网络/API 失败会保留 Keystore 值，方便重试。
- The save action is disabled while verification is running and all setup messages are localized. / 验证期间保存按钮不可重复点击，配置提示已本地化。
- Historical README, ROADMAP notes, and Releases remain intact. / 历史 README、ROADMAP 说明和 Releases 均保留。

## Safety boundary / 安全边界

OpenApp-only and local-first. No Luogu main-site password, Cookie, Session, CSRF login, cloud account, cross-device sync, background submission, or automatic POST retry is added. / 仅使用 OpenApp、本地优先；不新增洛谷主站密码、Cookie、Session、CSRF 登录、云端账号、跨设备同步、后台提交或 POST 自动重试。

Official reference / 官方依据: https://docs.lgapi.cn/open/api/auth
