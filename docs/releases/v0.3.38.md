# OJ NEXUS v0.3.38 — OpenApp action intent clarity / OpenApp 操作意图明确化

## Highlights / 重点

- The real Luogu OpenApp workspace action is now labelled `SUBMIT`. / 真实洛谷 OpenApp 工作区操作现在显示为“提交”。
- `RUN` remains available only to a gateway that explicitly supports custom-input execution. / “运行”仍只对明确支持自定义输入运行的网关开放。
- Busy state continues to show `WORKING`; submission requests and result polling are unchanged. / 忙碌状态继续显示“处理中”；提交请求和结果查询不变。
- Package identity is `versionName=0.3.38`, `versionCode=38`. / 安装包身份为 `versionName=0.3.38`、`versionCode=38`。
- `SHA256SUMS-v0.3.38.txt` accompanies the APK. / APK 附带 `SHA256SUMS-v0.3.38.txt`。

## Safety boundary / 安全边界

This phase clarifies the visible action only. It does not add a local compiler, custom-input
runner, Luogu main-site password, Cookie, Session, CSRF state, cloud account, cross-device sync,
or automatic POST retry. / 本阶段仅明确可见操作，不新增本地编译器、自定义输入运行器、洛谷主站密码、
Cookie、Session、CSRF 状态、云端账号、跨设备同步或自动 POST 重试。
