# OJ NEXUS v0.3.45 — Submission title context / 提交题名上下文

## Highlights / 重点

- Local submission history keeps the public problem title beside the PID when available. /
  本地提交历史在可用时会在 PID 旁保留公开题目标题。
- PID remains the only submission identity; the title is display metadata only. /
  PID 仍是唯一提交身份；题名仅用于本地展示。
- Room migration 10→11 preserves existing request rows and gives legacy rows a null title. /
  Room 10→11 迁移保留现有请求记录，旧记录的题名为空。
- The title never enters the official Luogu Open Platform request DTO. /
  题名不会进入官方洛谷 Open Platform 请求 DTO。
- Package identity is `versionName=0.3.45`, `versionCode=45`. /
  安装包身份为 `versionName=0.3.45`、`versionCode=45`。
- `SHA256SUMS-v0.3.45.txt` accompanies the signed APK. / 签名 APK 附带
  `SHA256SUMS-v0.3.45.txt`。

## Safety boundary / 安全边界

This is a local display-context and additive migration change. It does not add main-site
passwords, Cookie, Session, CSRF state, cloud service, cross-device sync, local compiler,
custom-input runner, background submission, or automatic POST retry. /
本版本仅增加本地展示上下文和非破坏性数据库迁移，不新增主站密码、Cookie、Session、CSRF 状态、云服务、
跨设备同步、本地编译器、自定义输入运行器、后台提交或自动 POST 重试。


The signed APK is installed over the existing emulator app without clearing data. The emulator
remains online; no shutdown or data reset is performed. / 签名 APK 在不清除数据的情况下覆盖安装到现有模拟器。
模拟器保持在线，不执行关机或数据重置。

Earlier release notes, commits, tags, and published Releases remain preserved. /
更早的发布说明、commit、标签和已发布 Release 均保留。
