# OJ NEXUS v0.3.41 — Safe OpenApp credential replacement / 安全 OpenApp 凭据更换

## Highlights / 重点

- Configured users can replace an OpenApp credential from a blank editor. / 已配置用户可以通过空白编辑器更换 OpenApp 凭据。
- The candidate is verified with read-only `GET /judge/quotaAvailable` before storage changes. / 候选凭据会先通过只读 `GET /judge/quotaAvailable` 验证，再修改本地存储。
- Unauthorized, forbidden, network, API, and write failures preserve the existing credential. / 未授权、禁止访问、网络、API 和写入失败都会保留原凭据。
- The editor provides an explicit `CANCEL` action and never reads or renders the stored secret. / 编辑器提供明确的“取消”操作，绝不读取或显示已保存密钥。
- Package identity is `versionName=0.3.41`, `versionCode=41`. / 安装包身份为 `versionName=0.3.41`、`versionCode=41`。
- `SHA256SUMS-v0.3.41.txt` accompanies the signed APK. / 签名 APK 附带 `SHA256SUMS-v0.3.41.txt`。

## Safety boundary / 安全边界

This release supports only the official Luogu Open Platform credential. It does not add
main-site passwords, Cookie, Session, CSRF state, cloud account, cross-device sync, local
compiler, custom-input runner, background submission, or automatic POST retry. / 本版本仅支持官方
洛谷 Open Platform 凭据，不新增主站密码、Cookie、Session、CSRF 状态、云端账号、跨设备同步、
本地编译器、自定义输入运行器、后台提交或自动 POST 重试。
