# v0.3.65 — Command Palette Direct Jump

## Highlights

- Added deterministic direct local problem queries to COMMANDS: `cf`, `codeforces`, `ac`,
  `atcoder`, `lg`, `luogu`, and `search` prefixes are supported.
- Added the blue-rail `DIRECT QUERY` result with visible target text and button semantics.
- Direct queries open the existing Problems library and prefill its judge and text filter once;
  ordinary commands and empty/error behavior remain unchanged.

## Scope

This is a local-only presentation, parsing, and navigation change. It adds no network request,
remote catalog access, database migration, credential storage, compiler, or persisted search
state. The existing Problems filter remains the source of truth.
