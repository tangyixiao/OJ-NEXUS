# OJ NEXUS v0.3.27 — Luogu public sync boundary / 洛谷公开同步边界

## Highlights / 主要变化

- **Public-only Luogu sync / 洛谷仅同步公开数据** — Account sync now runs profile, rating,
  contests, and problem catalog stages only. 账号同步现在只运行资料、Rating、竞赛和题库阶段。
- **No false partial state / 不再误报部分成功** — The unsupported submission-record request is
  no longer called, so a successful public run reaches `SUCCESS` instead of known
  `PARTIAL/AUTH_REQUIRED`. 不再调用未支持的提交记录请求，公开同步成功时返回 `SUCCESS`，不再被已知
  的 `PARTIAL/AUTH_REQUIRED` 污染。
- **OpenApp workflow preserved / OpenApp 流程保留** — Local Luogu OpenApp submission jobs and
  result workers remain separate and available in the submission center. 本地洛谷 OpenApp 提交任务及
  结果 Worker 仍由提交中心独立提供。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and commit explanations use
  English + Chinese. Previous phase notes and Releases remain preserved. README、路线图、本 Release
  和 commit 说明使用中英文结合；之前的阶段说明和 Releases 继续保留。

## Safety boundary / 安全边界

Private submission history remains outside the public Luogu adapter; no fabricated attempts are
imported. This release adds no main-site password, Cookie, Session, CSRF login, cloud account,
cross-device sync, local compiler, or custom-input runner. / 私有提交历史仍不属于洛谷公开适配器，不会
伪造导入提交记录。本版本不新增主站密码、Cookie、Session、CSRF 登录、云端账号、跨设备同步、本地
编译器或自定义输入运行器。
