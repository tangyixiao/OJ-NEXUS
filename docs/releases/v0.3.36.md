## Signing and scope / 签名与范围

This direct-download artifact is a Release build signed with the machine's standard Android
debug keystore. The keystore is not included in the repository or release assets. Users should
use the checksum file and install only from the published GitHub Release. A production private
signing key and Play Store publication are outside this local-first project scope. / 本直下载产物是使用
本机标准 Android debug keystore 签名的 Release 构建。密钥库不会进入仓库或 Release 资产。用户应使用
校验文件，并仅从已发布的 GitHub Release 安装。生产私钥和 Play Store 发布不在本地优先项目范围内。

No Luogu endpoint, credential flow, database migration, cloud service, cross-device sync, local
compiler, custom-input runner, or automatic submission retry is added. / 本版本不新增洛谷接口、凭据流程、
数据库迁移、云端服务、跨设备同步、本地编译器、自定义输入运行器或自动提交重试。
