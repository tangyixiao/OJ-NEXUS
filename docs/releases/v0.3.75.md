# OJ NEXUS v0.3.75 — Note Index and Shared Layout Font Scaling

## Included

- Phase 77: the `NOTE INDEX` problem-library scope, listing every problem whose saved notes
  carry text, newest note first, with field-scope search, judge filter, and unsolved-only
  filter. Local read-only projection; no migration and no new table.
- Shared layout at large font sizes: section headings wrap within the space left by their
  trailing action with a tokenized gap, and bottom navigation keeps a 60dp minimum while
  growing to fit wrapped labels. All five tabs stay equally tall with icon and label rows
  aligned; the full-width 48dp command row and navigation-bar inset are preserved.

## Safety boundary

The release remains local-first and public-data-only. No main-site password, Cookie, Session,
CSRF login, cloud account, cross-device sync, local compiler, custom-input runner, background
submission, or automatic POST retry is included.
