# v1.0.5 — Portable Workspace Import/Export — Release Notes

Date: 2026-11-19

Branch: `codex/release-v1.0.5` (version bump only); GitHub publication runs

SHA256SUMS automatically.

## What changed since 1.0.4

The 1.0.4 → 1.0.5 window carries the Phase 132 delivery: the Android app can
now move its workspace to and from a portable, judge-agnostic package file.
Everything below ships in the APK; the network still only syncs public
handles, no credential ever leaves the device, and portable packages exclude
credentials, source code, input history and account configuration by design.

- **Portable Workspace screen (Phase 132).** Settings gains a PORTABLE
  WORKSPACE entry: pick a package file, read a frozen preview (format version,
  counts per tier, sources), then apply or reject explicitly. Nothing is
  written before the explicit confirm; cancel and reject leave no partial
  records.
- **Strict import contract.** The codec rejects unknown format versions,
  unknown fields, duplicate identities, missing references, count mismatches,
  size-limit violations and path-unsafe names with stable typed reasons; the
  preview freezes the verdict before anything is staged.
- **Lossless export.** Export re-reads the tiered archive store and emits the
  package in canonical form; the mixed golden round trip (import → apply →
  export) reproduces the pinned canonical identity
  `81bb13c1…d44`.
- **Transactional archive storage.** Imported records land in the tiered
  portable archive (schema v8) inside a single transaction with rollback; a
  failed apply clears staged bytes, and a superseding intent aborts an
  in-flight one.
- **Bilingual copy.** All new user-facing strings ship with zh-rCN mirrors
  enforced by the localization parity test.

## Assets and signing

The release workflow publishes `OJ-NEXUS-v1.0.5.apk` when release-keystore
secrets (`ANDROID_KEYSTORE_*`) are configured; without them it publishes the
unsigned release APK (clearly named `...-UNSIGNED-REQUIRES-SIGNING.apk`)
plus a debug-signed CI-key APK that installs directly but cannot upgrade in
place over differently-signed builds. Verify the SHA-256 sums before
installing. minSdk 26 (Android 8.0+), targetSdk 37.
