# v0.3.69 — OJ Connector Center

## Highlights

- Settings now starts with an `OJ CONNECTOR CENTER` for every registered judge.
- Each connector row exposes honest connection state, persisted sync phase, receipt coverage,
  last-success age, and active stage.
- `SYNC ALL` queues one explicit refresh per connected judge that advertises `BACKGROUND_SYNC`.
- Duplicate `SYNC ALL` actions are ignored while the queue operation is in flight.
- Disconnected and unsupported judges remain visible but are not queued.

## Scope

The center projects existing Room data and reuses the existing `JudgeSyncWorker` and
`JudgeSyncDispatcher` path. It adds no passwords, cookies, main-site sessions, automatic
submissions, database migrations, or new background work.
