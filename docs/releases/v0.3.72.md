# OJ NEXUS v0.3.72 — Action Continuity

## Included

- Refreshes the local epoch day at startup, the next local midnight, and app resume.
- Rebinds Dashboard, Training, Review Run, and analytics Room streams to the current day.
- Projects Dashboard commands to exact session, task, review, submission request, contest, and
  settings actions with deterministic precedence.
- Adds a one-shot submission request context and minimum-height command cells for large text.

## Safety boundary

The change remains local-first. It adds no automatic submission, credentials, cookies, passwords,
new network response, or source/custom-input persistence.
