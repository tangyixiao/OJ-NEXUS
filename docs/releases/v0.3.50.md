# OJ NEXUS v0.3.50 — Review triage / 复习分诊台

## What changed

- Added a local `TRAINING PULSE` to the Training screen with overdue, today, and later review counts.
- Added `ALL`, `DUE NOW`, and `UPCOMING` queue filters with short reduced-motion-safe transitions.
- Added a real `START NEXT` action that opens the earliest due review; when the queue is empty,
  the action is visibly disabled and does not invent an ID.
- Kept the existing review rows, problem navigation, session flow, recommendations, tasks,
  knowledge, history, and empty states intact.
- Made queue due highlighting use the Training ViewModel's calendar snapshot for consistent state.
