# OJ NEXUS v0.3.23 — Local Luogu workspace drafts / 本地洛谷工作区草稿

## Highlights / 主要变化

- **Local draft restore / 本地草稿恢复** — Each Luogu problem workspace now keeps one Room draft
  keyed by judge and PID, restoring code, optional input, language, and O2 on reopen. 每道洛谷题目
  的工作区现在按评测平台和题号保存一份 Room 草稿，重新打开时恢复代码、可选输入、语言和 O2。
- **Safe save behavior / 安全保存行为** — Editor writes use a 300 ms debounce, show localized
  persistence state, and page/system back flushes the latest edit before navigation. 编辑写入采用
  300 毫秒防抖，显示本地保存状态，页面返回和系统返回前会先落盘最新编辑。
- **Migration and backup / 迁移与备份** — Schema 10 adds only `workspace_drafts`; Room backup/import
  includes drafts, while submission request metadata still excludes source code and input。Schema 10
  只新增 `workspace_drafts` 表；Room 备份/恢复包含草稿，提交请求元数据仍不保存源代码和输入。
- **Bilingual history / 双语历史** — README, roadmap, this Release, and the commit explanation
  remain English + Chinese; previous phase notes and Releases were not removed. README、路线图、本
  Release 和 commit 说明继续中英文结合，之前的阶段说明和 Releases 没有删除。

## Scope / 范围

This is a local-first editor continuity improvement. Drafts are never transmitted and do not add
Luogu main-site password, Cookie, Session, CSRF login, cloud account, cross-device sync, local
compiler, custom-input runner, or automatic POST retry. / 本版本是本地优先的编辑连续性改进，草稿不会
上传；不新增洛谷主站密码、Cookie、Session、CSRF 登录、云端账号、跨设备同步、本地编译器、自定义输入
运行器或自动提交重试。
