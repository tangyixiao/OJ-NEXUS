# OJ NEXUS v0.3.35 — Luogu result query alignment / 洛谷结果查询对齐

## Highlights / 重点

- Luogu Open Platform result polling now calls `GET /judge/result?id=<RequestId>`. / 洛谷 Open
  Platform 结果轮询现在调用 `GET /judge/result?id=<RequestId>`。
- The APK reports `versionName=0.3.35` and `versionCode=35`. / APK 报告
  `versionName=0.3.35` 和 `versionCode=35`。
- The HTTP contract test prevents regression to the incompatible path form. / HTTP 契约测试防止回归到
  不兼容的路径形式。
- Existing Pending, partial, terminal, WebSocket, and local recovery behavior is preserved. / 现有
  Pending、部分结果、终态、WebSocket 和本地恢复行为保持不变。

## Scope / 范围

This release corrects the documented result-request shape only. It adds no new login mode,
main-site password, Cookie, Session, CSRF state, cloud service, local compiler, custom-input
runner, automatic POST retry, or public submission-history import. / 本版本仅修正文档规定的结果请求形式，
不新增登录模式、主站密码、Cookie、Session、CSRF 状态、云端服务、本地编译器、自定义输入运行器、自动 POST
重试或公开提交历史导入。
