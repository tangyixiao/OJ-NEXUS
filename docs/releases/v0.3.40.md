# OJ NEXUS v0.3.40 — OpenApp credential input validation / OpenApp 凭据输入校验

## Highlights / 重点

- Blank or whitespace-only OpenApp user/secret input is rejected locally before storage or quota verification. / 空白或仅空格的 OpenApp 用户/密钥会在存储或额度验证前被本地拒绝。
- Missing fields show specific localized feedback. / 缺失字段显示对应的本地化提示。
- Stored secrets remain Keystore-backed and are never read back into the editor. / 已保存密钥继续由 Keystore 保护，绝不会回读到编辑框。
- Package identity is `versionName=0.3.40`, `versionCode=40`. / 安装包身份为 `versionName=0.3.40`、`versionCode=40`。
- `SHA256SUMS-v0.3.40.txt` accompanies the APK. / APK 附带 `SHA256SUMS-v0.3.40.txt`。

## Safety boundary / 安全边界

This phase changes only local input validation and error presentation. It does not add in-place
credential replacement, main-site password, Cookie, Session, CSRF state, cloud account,
cross-device sync, local compiler, custom-input runner, or automatic POST retry. / 本阶段仅修改本地输入校验和
错误展示，不新增原地更换凭据、主站密码、Cookie、Session、CSRF 状态、云端账号、跨设备同步、本地编译器、
自定义输入运行器或自动 POST 重试。
