# OJ NEXUS v0.3.54 — Submission Control Tower / 提交控制塔

## Highlights

- Added a local `SUBMISSION PULSE` with total, pending, ready, and failed request counts.
- Added `ALL`, `PENDING`, `READY`, and `FAILED` filters that preserve source order and keep
  unknown statuses visible in ALL.
- Added `CLEAR FILTER` for returning to the complete local request list without modifying jobs.
- Kept existing result checks, background queue/retry actions, request metadata, and problem
  workspace navigation intact.
- Added reduced-motion-safe 200ms count and list transitions with localized accessibility labels.

Package identity: `versionName=0.3.54`, `versionCode=54`.

## Verification

Verification is recorded after the final serial test, build, lint, APK install, and emulator
interaction pass.

## Scope

This is a local presentation and list-filtering release. It adds no network fields, database
migration, credentials, passwords, Cookie, Session, CSRF state, cloud service, cross-device sync,
local compiler, custom-input runner, background submission, bulk retry, or automatic POST retry.
