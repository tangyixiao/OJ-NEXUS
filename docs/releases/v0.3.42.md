# OJ NEXUS v0.3.42 — Luogu sample-pair compatibility / 洛谷样例对兼容

## Highlights / 重点

- Native Luogu problem details now decode live nested sample pairs in the form `[input, output]`. / 原生洛谷题目详情现在可以解码实时返回的 `[输入, 输出]` 嵌套样例对。
- Existing flat sample fixtures remain supported and preserve their order. / 现有扁平样例 fixture 继续支持并保持原有顺序。
- The fix stays at the network DTO boundary; the domain model, Room cache, and Compose screen remain stable. / 修复限定在网络 DTO 边界，领域模型、Room 缓存和 Compose 页面保持稳定。
- Package identity is `versionName=0.3.42`, `versionCode=42`. / 安装包身份为 `versionName=0.3.42`、`versionCode=42`。
- `SHA256SUMS-v0.3.42.txt` accompanies the signed APK. / 签名 APK 附带 `SHA256SUMS-v0.3.42.txt`。

## Safety boundary / 安全边界

This release does not add main-site passwords, Cookie, Session, CSRF state, cloud account,
cross-device sync, local compiler, custom-input runner, background submission, or automatic POST
retry. / 本版本不新增主站密码、Cookie、Session、CSRF 状态、云端账号、跨设备同步、本地编译器、
自定义输入运行器、后台提交或自动 POST 重试。
